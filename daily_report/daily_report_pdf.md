# daily_report_pdf.py 프로세스 및 기술 문서

## 1. 개요 (Overview)

`daily_report_pdf.py` 모듈은 **빗썸(Bithumb) 원화(KRW) 마켓에 상장된 전체 암호화폐**의 **일봉(Daily)** 시계열 데이터를 수집·분석하여, **일목균형표 기준선(26)이 하향 추세(우하향)인 상태에서 MACD선이 상향 추세(우상향 반전)를 보이는 코인(상승 다이버전스 / 모멘텀 반전 포착)**을 선별하고, **1코인당 1페이지 3단 시각화(일목+진한 거래량, MACD, RSI)** PDF 리포트를 자동 생성하는 프로그램입니다.

생성된 PDF 리포트는 `daily_report/report/` 디렉터리에 타임스탬프 파일명(`report_daily_YYYYMMDDHHMMSS.pdf`) 형태로 자동 저장됩니다.

---

## 2. 코인 포착 핵심 조건

```
                 [ 일봉 다이버전스 / 모멘텀 반전 포착 조건 ]
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. 일봉 일목균형표 기준선(26봉) 하향 추세 (최근 5봉 기준선 감소 / 기울기 < 0)│
│ 2. 일봉 MACD(12,26) 선 상향 추세 (최근 3~5봉 MACD 상승 / 기울기 > 0)          │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 검증 지표 | 조건 및 매매 전략적 의미 |
| :--- | :--- |
| **일봉 기준선(26)** | `기준선 하향 추세` : 중기 가격 지지선이 조정/하락 진행 중인 상태 |
| **일봉 MACD(12,26)** | `MACD선 상향 추세` : 주가 하락에도 단기 모멘텀이 상승 반전하는 긍정적 다이버전스(Bullish Divergence) 포착 |

## 3. 프로세스 동작 흐름도 (Data & Execution Flow)

```mermaid
flowchart TD
    A[프로그램 시작: daily_report/daily_report_pdf.py] --> B[빗썸 API로 원화 KRW 전체 마켓 목록 조회]
    B --> C[ThreadPoolExecutor 멀티스레드 스캔 생성 max_workers=6]
    C --> D[각 코인별 일봉 200개 시계열 수집 및 일목/MACD/RSI 계산]
    D --> E{포착 조건 검사\n1) 기준선 하향 추세\n2) MACD선 상향 추세}
    E -- No --> Z[탈락]
    E -- Yes --> H[포착 코인 리스트에 저장 및 MACD 기울기 계산]
    H --> I[MACD 기울기 내림차순 정렬]
    I --> J[PdfPages 시작: daily_report/report/report_daily_YYYYMMDDHHMMSS.pdf]
    J --> K[Page 1: 종합 요약 표 Summary Table 페이지 렌더링]
    K --> L[Page 2~N: 개별 코인당 한 페이지 3단 시각화 차트 렌더링]
    L --> M[PDF 파일 저장 완료]
    M --> N[프로세스 완료]
```

## 4. PDF 리포트 구성 및 차트 시각화 레이아웃 (1 코인 1 페이지)

### 4.1. 표지 및 종합 요약 표 페이지 (Page 1)
- 스캔 일시, 필터 조건, 전체 포착 종목 수 표기.
- 마켓코드, 한글명, 영문명, 현재가, 일봉 전환선/기준선(26), 기준선 기울기, MACD, MACD 기울기, RSI 요약 표 수록.

### 4.2. 코인별 3단 차트 레이아웃 (Page 2 ~ N)
한 코인당 **1개 페이지**에 3단 서브플롯(Top-Middle-Bottom)으로 구성됩니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1단: 일봉 주가 + 일목균형표(9,26,52) + 진한 거래량 (TwinX Bar Chart)        │
├─────────────────────────────────────────────────────────────────────────────┤
│ 2단: MACD (12, 26, 9) (MACD 선, Signal 선, Oscillator Histogram Bar)        │
├─────────────────────────────────────────────────────────────────────────────┤
│ 3단: RSI (14) (RSI 선, 70/30 과매수/과매도 기준선)                           │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 세부 차트 구성 요소:
1. **1단 (주가 & 일목균형표 & 거래량)**:
   - **종가 선**: 검은색 실선
   - **전환선(9봉)**: 빨간색 실선 (`#e31a1c`)
   - **기준선(26봉)**: 파란색 실선 (`#1f78b4`)
   - **선행스팬1 (26봉 시프트)**: 초록색 점선 (`#33a02c`)
   - **선행스팬2 (52봉/26봉 시프트)**: 주황색 점선 (`#ff7f00`)
   - **구름대**: 양운(연한 초록), 음운(연한 분홍) 채우기
   - **진한 거래량 (TwinX)**: 상승 봉은 진한 빨강(` #c0392b`), 하락 봉은 진한 파랑(` #2980b9`), 불투명도 `alpha=0.65` 적용
2. **2단 (MACD)**:
   - MACD 선(파랑), Signal 선(빨강 점선), Oscillator 히스토그램 바(상승 빨강 / 하락 파랑)
3. **3단 (RSI)**:
   - RSI(14) 보라색 실선, 과매수(70) 빨강 점선, 과매도(30) 파랑 점선
