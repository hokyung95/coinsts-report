# onehour_rsi60_75_simulation_report_v2.py 시뮬레이션 모듈 및 성과 기술 문서

## 1. 개요 (Overview)

`onehour_rsi60_75_simulation_report_v2.py` 모듈은 **빗썸(Bithumb) 원화(KRW) 마켓 상장 전체 암호화폐**를 대상으로 최근 **200개 1시간봉(60분봉)** 시계열 데이터를 수집하여, **1시간봉 최근 20개봉 RSI(14) 60~75 비율 80% 이상 조건 매수** 및 **체결가 < 전환선(9) 데드크로스 이탈 매도(스탑로스 -3.0% 포함) 전략**에 대한 시뮬레이션(백테스팅)을 수행하고 성과 지표(승률, 평균 수익률, 손익비, 최대 수익/손실률 등)를 분석하는 v2 모듈입니다.

---

## 2. v2 시뮬레이션 매수 / 매도 알고리즘 규격

```
            [ 1시간봉 RSI 60~75 (80%+) 매수 & 체결가 < 전환선(9) 매도 v2 규격 ]
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 1. 백테스팅 타깃: 빗썸 원화(KRW) 마켓 전체 코인 (최근 200개 1시간봉)                     │
│ 2. 매수 로직 (Buy Entry):                                                              │
│    - N번째 1시간봉 기준 최근 20개봉 (N-19 ~ N) 중 60.0 <= RSI(14) <= 75.0 만족 봉 수 >= 16개 │
│    - 미보유 상태 시 해당 조건 만족 봉(N번째 봉) 종가로 매수 진입                           │
│ 3. 매도 로직 (Sell Exit - v2):                                                         │
│    - ① [스탑로스 매도]: 진입가 대비 low_price 손실률 <= -3.0% 시 즉시 스탑로스 청산        │
│    - ② [체결가 < 전환선 매도]: 보유 상태 시 거래가격(종가) < 일목 전환선(9) 이탈 시 매도   │
│    - ③ [마지막봉 청산]: 200번째 봉 도달 시 종가로 강제 청산                                 │
│ 4. 산출 메트릭: 승률(%), 거래당 평균 수익률(%), 손익비(Profit Factor), 최대 수익/손실률     │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 3. 프로세스 동작 흐름도

```mermaid
flowchart TD
    A[시뮬레이션 시작: onehour_rsi60_75_simulation_report_v2.py] --> B[빗썸 REST API: 원화 KRW 전체 마켓 200개 1시간봉 수집]
    B --> C[ThreadPoolExecutor 스레드 풀 병렬 수집 및 지표 산출]
    C --> D[시계열 20~200번째 봉 순회: 20봉 RSI 60~75 80%+ 매수 조건 탐색]
    D -->|매수 포착| E[포지션 생성 및 청산 조건 검사: 스탑로스 -3.0% OR 종가 < 전환선9]
    E -->|손절 / 전환선 하회 이탈| F[매도 청산 & 거래별 수익률, 보유 봉 수 산출]
    F --> G[전체 거래 성과 집계: 총 거래 수, 승률, 평균 수익률, Profit Factor]
    G --> H[PdfPages 시뮬레이션 종합 리포트 생성]
    H --> I[Page 1: 성과 종합 요약 표]
    I --> J[Page 2+: 개별 거래 상세 세부 내역 표]
    J --> K[Page N+: 코인별 매수/매도 표시 3단 차트 렌더링]
    K --> L[PDF 리포트 저장 완료]
```

## 4. PDF 성과 리포트 구성

### 4.1. 성과 종합 요약 표 페이지 (Page 1)
- 스탑로스(-3.0%) 및 체결가 < 전환선 매도 설정, 분석 대상 코인 수, 거래 발생 코인 수, 총 거래 횟수 표기
- **전체 승률 (Win Rate %)**, **거래당 평균 수익률 (%)**, **손익비 (Profit Factor)**, **최대 수익률 / 최대 손실률 (%)**, **평균 포지션 보유 시간(시간)** 수록

### 4.2. 개별 거래 상세 세부 내역 표 페이지
- 실행된 매수/매도 거래의 마켓코드, 코인명, 매수가, 매도가, 수익률(%), 보유시간, 진입/청산 시점, 청산 사유(체결가 < 전환선 / 스탑로스 / 마지막봉) 수록

### 4.3. 코인별 시뮬레이션 차트 페이지
- 60분봉 3단 서브플롯:
  - **1단**: 가격 + 일목 전환선/기준선 + 거래량 + 매수($\blacktriangle$, 녹색) / 매도($\blacktriangledown$, 붉은색) 마커 및 연결선
  - **2단**: MACD
  - **3단**: RSI(14) (60~75 주황색 음영 구간 표시)
