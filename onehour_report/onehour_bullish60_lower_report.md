# onehour_bullish60_lower_report.py 프로세스 및 기술 문서

## 1. 개요 (Overview)

`onehour_bullish60_lower_report.py` 모듈은 **빗썸(Bithumb) 원화(KRW) 마켓에 상장된 전체 암호화폐**를 대상으로 **현재 1시간봉이 체결가(종가) > 전환선(9) > 기준선(26)** 정배열 상태이면서, **1시간봉 기준선(26)의 기울기 각도가 0° 이상 5° 이하(수평~완만한 우상향)**이고, **최근 10시간(10개 60분봉) 중 정배열을 유지한 봉의 개수가 6개 이하(<= 6봉)**인 초기 우상향 전환 코인을 포착하여, 각 포착 코인별 **60분봉(1시간봉) 및 일봉(Daily) 기준 일목균형표(전환선9, 기준선26), MACD(12,26,9), RSI(14)** 지표를 계산하고, **코인당 한 페이지 듀얼 3단 시각화(좌측: 1시간봉, 우측: 일봉)** PDF 종합 리포트를 자동 생성하는 프로그램입니다.

생성된 PDF 리포트는 `onehour_report/report/` 디렉터리에 타임스탬프 파일명(`onehour_bullish60_lower_report_YYYYMMDDHHMMSS.pdf`) 형태로 자동 저장됩니다.

## 2. 수집 및 분석 규격

```
        [ 빗썸 1시간봉 정배열 & 기준선 각도 0°~5° & 10h 중 정배열 <= 6봉 규격 ]
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. API 호출:                                                                │
│    - 1시간봉: https://api.bithumb.com/v1/candles/minutes/60?market={market}&count=200 │
│    - 일  봉: https://api.bithumb.com/v1/candles/days?market={market}&count=200       │
│ 2. 수집 대상: 빗썸 원화(KRW) 마켓 상장 전체 암호화폐 (약 480개)              │
│ 3. 포착 조건 (1시간봉 기준):                                               │
│    - 현재 1시간봉 정배열: 체결가(Close) > 전환선(9) > 기준선(26)             │
│    - 기준선 기울기 각도: 0° <= angle_deg <= 5.0°                            │
│    - 최근 10시간 중 정배열 유지 봉 수: 1 <= bullish_count <= 6              │
│ 4. 지표 계산: 일목균형표 (9, 26, 52), MACD (12, 26, 9), RSI (14), 거래량         │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 지표 항목 | 파라미터 및 설명 |
| :--- | :--- |
| **일목균형표** | `전환선(9봉)`, `기준선(26봉)`, `선행스팬1(26봉 시프트)`, `선행스팬2(52봉/26봉 시프트)` |
| **MACD** | `Short=12`, `Long=26`, `Signal=9` (MACD 선, Signal 선, Oscillator Histogram) |
| **RSI** | `Period=14` (RSI 선, 70/30 과매수/과매도 기준선) |
| **거래량** | `candle_acc_trade_volume` (진한 색상 거래량 막대 차트 TwinX Overlay) |

```mermaid
flowchart TD
    A[프로그램 시작: onehour_bullish60_lower_report.py] --> B[빗썸 API로 원화 KRW 전체 마켓 목록 조회]
    B --> C[ThreadPoolExecutor 멀티스레드 스캔 생성 max_workers=8]
    C --> D[각 코인별 1시간봉 수집: 현재 정배열 & 기준선 각도 0°~5° & 10h 중 정배열 <= 6봉 검증]
    D -->|조건 만족 코인| E[일봉 추가 수집 및 60m/일봉 일목·MACD·RSI 지표 계산]
    E --> F[수집 데이터 검증 및 기준선 각도오름차순 정렬]
```

## 4. PDF 리포트 구성 및 차트 시각화 레이아웃 (1 코인 1 페이지 듀얼 3단)

### 4.1. 표지 및 종합 요약 표 페이지
- 스캔 일시, 분석 조건, 포착 대상 코인 수 표기.
- 마켓코드, 한글명, 영문명, 현재가, 기준선 각도(°), 10h 중 정배열 개수, 60m 전환선/기준선/이격률/RSI/MACD, 일봉 RSI 요약 표 수록.

### 4.2. 코인별 듀얼 3단 차트 레이아웃 (Page 2 ~ N)
한 코인당 **1개 페이지**에 3x2 서브플롯(좌: 1시간봉 / 우: 일봉)으로 구성됩니다.

```
┌──────────────────────────────────────────┬──────────────────────────────────────────┐
│ [좌측: 1시간봉(60m)]                     │ [우측: 일봉(Daily)]                      │
├──────────────────────────────────────────┼──────────────────────────────────────────┤
│ 1단: 1시간봉 가격+일목(9,26,52)+진한거래량│ 1단: 일봉 가격+일목(9,26,52)+진한거래량 │
├──────────────────────────────────────────┼──────────────────────────────────────────┤
│ 2단: 1시간봉 MACD (12, 26, 9)            │ 2단: 일봉 MACD (12, 26, 9)               │
├──────────────────────────────────────────┼──────────────────────────────────────────┤
│ 3단: 1시간봉 RSI (14)                    │ 3단: 일봉 RSI (14)                       │
└──────────────────────────────────────────┴──────────────────────────────────────────┘
```
