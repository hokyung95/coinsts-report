# 암호화폐 30일 일목균형표 기준선(30일) U자형 턴어라운드 분석 및 롤링 백테스팅 가이드

## 1. 목표 및 개요 (Goal & Overview)

24시간 365일 연중무휴 거래되는 **암호화폐(코인) 마켓(월 30일)** 특성에 맞춰 **30일 암호화폐 전용 일목균형표(10, 30, 60, 30)**를 적용합니다. **기준선(Kijun-sen, 30일)**이 그리는 **U자형 턴어라운드 (1단계 하락 ➔ 2단계 수평 바닥 ➔ 3단계 우상향 전환)** 패턴을 포착하고, **과거 200일간 하루씩 롤링 시뮬레이션(Rolling Backtest)**을 수행하여 **거래량 상관성** 및 **발생 이후 주가 상승 성과(5일, 10일, 20일 후 수익률 및 승률)**를 정량 검증하는 시스템입니다.

## 2. 암호화폐 30일 전용 일목 파라미터 및 U자형 패턴 원리

### 2.1. 암호화폐 30일 전용 지표 수식
$$\text{암호화폐 30일 기준선(Kijun-sen)} = \frac{\text{최근 30일간 최고가} + \text{최근 30일간 최저가}}{2}$$

* **전환선**: **10일** (최근 10일간 최고/최저 중간값 - 월 30일의 1/3)
* **기준선**: **30일** (최근 30일간 최고/최저 중간값 - 1개월 30일 기준선)
* **선행스팬 1**: `(전환선 + 기준선) / 2` 를 **미래 30일** 앞으로 시프트
* **선행스팬 2**: **60일** (최근 60일간 최고/최저 중간값 - 2개월)을 **미래 30일** 앞으로 시프트

### 2.2. U자형 턴어라운드 3단계 형성 과정

```
       [ 1단계: 하락 구간 ]        [ 2단계: 수평 바닥 구간 ]      [ 3단계: 우상향 전환 ]
  30일전 대비 15일전 하락 ➔   30일간 신저가 경신 중단 ➔  신고가 경신 / 기준선30 우상향
    (장기 하락세 추세)       (세력 매집 및 바닥 형성)   (중기 추세 턴어라운드 확정)
```

1. **1단계 (하락 구간)**: 30일간의 최고가가 지속 하락하거나 신저가가 경신되면서 수급 균형선이 아래로 향하는 장기 하락세 국면입니다.
2. **2단계 (U자 바닥 - 수평 구간)**: 주가가 더 이상 신저가를 경신하지 않고 좁은 박스권 횡보를 진행합니다. **과거의 폭락 가격대가 30일 계산 윈도우 밖으로 이탈**하면서 기준선 수치가 일직선 수평(Flat)으로 유지됩니다. 이는 **세력의 물량 소화 및 강력한 중기 바닥 지지선 구축**을 의미합니다.
3. **3단계 (U자 우측 - 우상향 전환)**: 횡보하던 주가가 박스권을 위로 뚫고 **30일간의 신분위 신고가를 경신**하기 시작할 때 수평이던 30일 기준선 수치가 비로소 위로 꺾여 올라갑니다. 이는 **중기 추세 턴어라운드(상승 전환)가 확정**되는 결정적 시그널입니다.
4. **주가(Price) 안착**: 우상향으로 꺾인 30일 기준선 위에 종가가 안착(Price $\ge$ Kijun30)하면 기준선이 가파른 상승 지지대 역할을 하게 됩니다.

## 3. HTS 조건검색식 설정 가이드 (30일 코인 기준)

HTS 및 검색 엔진 설정 시 파라미터를 **(10, 30, 60, 30)**으로 입력합니다.

| 조건 기호 | 검색 항목 | 세부 설정 값 | 의미 |
| :---: | :--- | :--- | :--- |
| **A** | **일목균형표 ➔ 기준선 추세** | `일목균형표(10, 30, 60)` : 30봉전 기준선 > 15봉전 기준선 | 1단계: 과거 하향 추세 |
| **B** | **일목균형표 ➔ 기준선 유지** | `일목균형표(10, 30, 60)` : 15봉전 기준선 == 2봉전 기준선 | 2단계: 최근 수평(Flat) 바닥 |
| **C** | **일목균형표 ➔ 기준선 추세** | `일목균형표(10, 30, 60)` : 1봉전 기준선 < 0봉전 기준선 | 3단계: 우상향 꺾임 발생 |
| **D** | **기술적분석 ➔ 주가/기준선** | `0봉전 종가 >= 0봉전 30일기준선` | 현재가 기준선 위 안착 |
