[목표]
일봉 차트에서 '일목균형표 기준선(26일)' 자체가 U자형 턴어라운드(하락 ➔ 수평 횡보 ➔ 우상향 전환)를 그리는 종목을 포착하는 로직/분석을 작성해 줘.
[기준선(Kijun-sen) U자형 패턴 상세 정의]
1. 1단계 (하락 구간): 
   - 약 20~30일 전 시점의 기준선 값 대비 10~15일 전 기준선 값이 하향 추세였을 것.
2. 2단계 (U자 바닥 - 수평 구간):
   - 최근 5~15봉 동안 기준선(26)의 값이 변하지 않고 수평(Flat) 상태를 유지하여 중기 바닥 지지선을 구축했을 것.
3. 3단계 (U자 우측 - 우상향 전환):
   - 최근 1~3봉 이내에 수평이던 기준선의 값이 상승 전환(Kijun[t] > Kijun[t-1])하며 우상향 꺾임이 발생할 것.
4. 주가(Price)와의 상호작용:
   - 현재 종가가 우상향으로 꺾인 기준선 위에 위치(Price >= Kijun)하거나, 캔들이 기준선을 양봉으로 상향 돌파(Golden Cross)할 것.
[요청 사항]
1. 이 기준선 U자형 패턴이 발생하는 시장적/기술적 의미(세력의 매집, 26일 고점/저점 변동 관계)를 간단히 설명해 줘.
2. 이 조건을 만족하는 종목을 검출하기 위한 [키움증권 HTS 조건검색식 수식 설정 방법]을 단계별로 작성해 줘.
3. 파이썬(Pandas)으로 기준선의 U자 턴어라운드를 감지하는 코드 로직 예시를 보여줘.
